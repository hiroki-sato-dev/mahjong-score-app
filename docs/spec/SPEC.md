# 仕様書

麻雀部スコア管理アプリの要件・仕様をまとめたマスタードキュメント。  
機能の実装が完了するたびに `docs/spec/features/<機能名>/` からマージされる。

---

## 概要

麻雀部のメンバーが半荘ごとのスコアを記録・管理し、成績やランキングを確認できるWebアプリケーション。

---

## 機能要件（MoSCoW法）

### Must（必須）

| 機能                 | 詳細                                 |
| -------------------- | ------------------------------------ |
| 部員登録・ログイン   | メール＋パスワード認証               |
| 半荘スコア入力・記録 | 4人の点数入力、日付・メンバー記録    |
| 成績確認             | 日別・累計の成績表示（タブ切り替え） |
| 収支計算             | 下記ルールに基づく自動計算           |
| ランキング           | 累計ポイント順                       |
| ロール管理           | 幹部 / 部員のロール分け              |
| チップの有無設定     | 半荘ごとにチップあり/なしを選択      |

#### 収支計算ルール

- 1000点 = 50P
- チップ = 100P（1枚あたり）
- 返し = 30000点
- ウマ（1着 +20P / 2着 +10P / 3着 -10P / 4着 -20P）

### Should（重要だがなくてもOK）

- 対戦履歴の検索・フィルター（日付・メンバーで絞り込み）
- プロフィール編集（表示名）

### Could（あると嬉しい）

- 成績グラフ・可視化（Recharts使用予定）
- 半荘ごとのコメント・メモ機能

### Won't（今回はやらない）

- 複数麻雀部の管理（マルチテナント）
- プッシュ通知
- 外部サービス連携（LINE通知等）

## 画面詳細

### 1. ログイン画面

- メールアドレス入力
- パスワード入力
- ログインボタン
- 新規登録リンク

### 2. 部員一覧画面

- 部員名・アバター
- 累計ポイント
- 試合数・平均P
- 最終対戦日
- 累計推移スパークライン

### 3. 半荘スコア入力画面

- 対戦日付
- 参加メンバー4人の選択（東南西北）
- 各自の点数入力
- チップあり/なし切り替え（トグル）
- チップ枚数入力
- 自動計算プレビュー（ウマ・オカ・P）
- 登録ボタン

### 4. 成績確認画面

タブで日別・累計を切り替え（URLクエリパラメータで管理）

**タブ: 日別**

- 日付選択
- その日の収支サマリ
- 半荘一覧（対戦メンバー・着順・素点・P）

**タブ: 累計**

- 期間フィルター（全期間・年・月）
- サマリー（累計P・平均P・1位率・最高/最低）
- 累計ポイント推移グラフ
- 月別収支グラフ
- 順位分布グラフ

### 5. ランキング画面

- 期間フィルター
- TOP3表彰台
- 累計ポイント横棒グラフ
- 4位以下リスト（順位・名前・累計P・試合数）

### 6. 幹部用管理画面

左サイドバーのナビゲーションで切り替え

**部員管理**

- 部員一覧テーブル（名前・メール・ロール・累計P・試合数・最終対戦）
- 部員追加
- ロール変更（幹部 / 部員）
- 部員削除

**スコア管理**

- 半荘記録一覧テーブル（日時・1〜4着・チップ）
- スコア編集
- 記録削除

## 画面遷移

```
ログイン
  └─ ロールで分岐
       ├─ 部員
       │    ├─ 部員一覧
       │    ├─ スコア入力
       │    ├─ 成績確認（日別 / 累計）
       │    └─ ランキング
       └─ 幹部
            ├─ 部員一覧〜ランキング（部員と同じ）
            └─ 管理画面
                 ├─ 部員管理
                 └─ スコア管理
```
